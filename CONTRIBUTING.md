# Cómo contribuir

Gracias por aportar a la Guía de agentes de LATAM-IA.

## Proponer un cambio

- Abrí una issue para proponer un tema nuevo o discutir cambios grandes.
- Para corregir errores de escritura o enlaces, podés enviar un pull request directamente.
- Buscá primero si ya existe una issue o un pull request sobre el tema.

## Enviar un pull request

1. Hacé un fork del repositorio y creá una rama para tu aporte.
2. Escribí en español claro. Explicá los términos técnicos y citá las fuentes originales.
3. Revisá la ortografía, los enlaces y los ejemplos antes de enviar el cambio.
4. Abrí un pull request que explique qué cambia y por qué.

No incluyas credenciales, datos personales ni material que no tengas derecho a compartir. Al contribuir, aceptás que tu aporte se distribuya bajo la licencia MIT del proyecto.

## Convivencia

Tratemos a las personas con respeto. Los comentarios deben centrarse en el contenido y permitir que personas con distintos niveles de experiencia puedan participar.
